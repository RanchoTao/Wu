## 教学模型：原创实现，全部为合成数据

所有交互图标注 **「概念演示 / Illustrative model — not empirical data」**。

1. 生长曲线：`y(t) = K / (1 + exp(-r(t-t₀)))`，`K=100`、`t₀=5`、`t∈[0,10]`。对任意 `r>0`，`y(t₀)=K/2=50`，但 `y′(t₀)=Kr/4` 不同。这是「同一个观测点不能识别完整轨迹」的构造性示例；不是一般性声称单点数据毫无信息。时间、表型值、r 均为无量纲教学量。
2. 首屏图版：同一 Logistic 函数的不同速率与拐点参数族作透视投影；第三轴表示假设参数，不是实际组织或已发现的生物结构。
3. 曲线到网络的滚动变形：曲线上的采样点插值至分层图节点，只是叙事性的视觉转换，**不是从曲线估计出网络的算法**。
4. 网络：固定的 9 节点、12 条有向有符号边，分属基因 / 细胞 / 性状三个示意层。实线箭头为正作用，虚线截线为负作用；边权是人为指定的无量纲系数。节点选择列出所有入边与出边。
5. 网络方程 `dxᵢ/dt = xᵢ(aᵢ + Σⱼ bᵢⱼxⱼ)` 仅用于解释正负系数（其他项固定且状态非负时）；页面**不求解该方程**，不声称图稳定、可拟合或具有生物因果证据。

「生命系统的数学」「从基因到网络，从数据到规律」及其它导语均为本项目原创编辑性文案，不以引号冒充教授原话。
