## 最终复核

报告：`test-results/final/report.json`。

**45 / 45 项通过**；浏览器脚本异常 0，本地资源加载失败 0，桌面、手机及来源页面的 WCAG 自动扫描均为 0 项违规。

最终的快速滚动复测还修复了可见性回调的批量事件边界：取最后一条 IntersectionObserver 状态，避免快速离屏再回屏后错误停绘。性能采样先确认测试页处于前台、曲面已恢复绘制，再测量帧数。

额外确认：

- 实际滚动完成曲线 → 网络的转换；点选节点会显示可读的最终网络。
- `K=100, t₀=5` 时，不同正速率都经过 50；移开观测线后数值分离；图的全部边都引用存在的节点。
- 暂停状态下 Canvas 静止，用户调整参数仍会触发绘图；550ms 内首页实测绘制 16 次，与 30fps 预算相符。这个短测量不等于在所有硬件上保证帧率。
- 无 JavaScript 时五篇论文、全部正文、来源与原创 SVG 后备图可读；非工作控件不显示。
- 模拟 Canvas 不可用时，首屏 SVG 后备图可见，基于 SVG 的网络选择仍工作。
- GitHub Pages 式项目子路径下，所有正文锚点与本地链接有效。
- 本地构建的 `SITE_URL` 注入逻辑另行检查，最终本地产物不写入假设域名；真实 URL 由官方 Pages 工作流在部署时提供。

`test-results/external-links.json` 保存正文最初 10 个唯一外部入口的 HTTP 检查：9 个 200，2002 年论文的 DOI 目标对自动请求返回 403。DOI 的 Crossref 登记与 PubMed 原摘要成功核实，已增加 [PubMed 备用入口](https://pubmed.ncbi.nlm.nih.gov/12196415/)。403 不作为论文不存在的证据，也不声称自动化能穿过出版商访问限制。
